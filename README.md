# 弹珠炼金术 · Pinball Alchemy

像素风物理弹珠挂机游戏。投放弹珠穿过钉子阵列，通过加减乘除等运算累积金币，归零进入下一周目获取数晶强化永久加成。通关 5 章后解锁无尽模式。

## 玩法循环

1. **放置钉子** — 在网格的可放置位置摆放运算符钉子（加/乘/除/指数/百分比/贤者等 13 种）
2. **投放弹珠** — 弹珠自顶部落下，碰撞钉子时数值按钉子运算符变化
3. **落底结算** — 弹珠落入底部槽位，按槽位倍率（中央 ×2）结算为金币
4. **归零重生** — 累积金币达到章节目标后归零，重置进度换取数晶（永久加成）
5. **Boss 战** — 章节进度达 90% 时触发 Boss，Boss 会自底部向上投掷负值球，需用正值球攻击 Boss 本体
6. **章节推进** — 击败 Boss 后归零解锁下一章，5 章全部通关解锁无尽模式

## 章节概览

| 章 | 名称 | 场景 | 钉子布局主题 | Boss |
|----|------|------|--------------|------|
| 1 | 学徒之始 | 零号镇 · 北境小村 | 漏斗形（上宽下窄） | 霜卫 |
| 2 | 符文觉醒 | 贤者遗迹 · 古老弹珠机废墟 | 菱形/钻石 | 骷髅守卫 |
| 3 | 熵的预兆 | 金辉城 · 繁华都市 | 上下宽带 + 中间稀疏 | 熵之幻影 |
| 4 | 归零之途 | 零之圣殿 · 极北圣地 | 外圈环绕 + 中央十字 | 幻彩守卫 |
| 5 | 贤者归来 | 无限回廊 · 贤者机器核心 | 密集满铺 | 熵核 |

每章有独立的开场剧情对话与钉子布局，玩家只能在预设布局位置放置钉子。

## 无尽模式

通关 5 章后解锁。无目标金币上限，持续挂机：
- 每达到金币阈值触发一位 Boss（5 位循环）
- 阈值渐进式增长（前 5 阶 ×3，之后 ×2）
- Boss 难度随阶段递增（球速/数值/频率）
- 无尽模式跳过开场对话，失败后可重新触发

## 核心系统

- **存档** — 3 个独立槽位，本地浏览器存储，支持导出/导入备份
- **数晶商店** — 归零获得的数晶用于购买永久加成（初始金币、弹珠价值、槽位倍率等）
- **弹珠系统** — 6 种元素弹珠（冰/火/雷/毒/圣光/暗影），各有特殊效果
- **技能系统** — 主动技能与被动强化
- **自动投放器** — 自动投球，可升级速度与数值
- **离线收益** — 关闭游戏后按时间累积金币（上限 8 小时）

## 技术栈

- **Phaser 3.80** — 2D 物理引擎与场景管理
- **Matter.js** — 弹珠物理碰撞
- **TypeScript 5.4** — 类型安全
- **Vite 5.2** — 构建与开发服务器
- **BigInt** — 大数运算（金币可达 1e28+）

## 项目结构

```
src/
├── main.ts                    # 入口
├── types.ts                   # 类型定义与平衡常量
├── data/
│   ├── chapters.ts            # 章节配置、自动器、数晶升级
│   ├── pegs.ts                # 钉子配置表（13 种运算符）
│   ├── pegLayouts.ts          # 每章钉子预设布局
│   ├── marbles.ts             # 元素弹珠配置
│   ├── skills.ts              # 技能配置
│   └── dialogues.ts           # 剧情对话
├── scenes/
│   ├── BootScene.ts           # 资源加载
│   ├── MenuScene.ts           # 主菜单（含设置/存档/商店/图鉴）
│   ├── ChapterSelectScene.ts  # 章节选择
│   ├── GameScene.ts           # 游戏主场景
│   └── OfflineReportScene.ts  # 离线收益报告
├── systems/
│   ├── GameState.ts           # 全局游戏状态
│   ├── SaveSystem.ts          # 存档读写
│   ├── BigNum.ts              # 大数运算
│   ├── EventBus.ts            # 事件总线
│   ├── DialogueSystem.ts      # 对话系统
│   └── BossBattleSystem.ts    # Boss 战逻辑
└── ui/
    ├── HUD.ts                 # 游戏 HUD
    └── icons.ts               # SVG 图标
```

## 开发

```bash
npm install        # 安装依赖
npm run dev       # 启动开发服务器
npm run build     # 类型检查 + 构建
npm run preview   # 预览构建产物
```

## 设置

游戏内设置弹窗提供：
- 音效 / 背景音乐开关
- 显示帧率
- **场景暗化**（0-80%，实时调整背景图亮度）
- 自动保存间隔（15/30/60 秒或关闭）
- Dev 模式金币倍率（开发测试用）
- 存档导出/导入/清空
